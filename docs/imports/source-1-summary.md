## 가져온 범위

`source/1`은 읽을 수 있는 복사 텍스트 1,223줄 뒤에 1,224번째 줄부터 큰 HTML/JavaScript 덩어리가 이어집니다. 읽을 수 있는 텍스트만 데이터로 가공했습니다. HTML, 스크립트, 플랫폼 UI 소스, 이미지 URL, 로고, 썸네일 등 시각 자산은 제외했습니다.

복사 텍스트에서 활동 단위별 JSON 파일을 만들었습니다. 게시물·영상·캐치 각각의 원본 URL/ID는 보이지 않아 `url`은 비워 두었습니다. 날짜와 계정 수치는 화면에 표시된 수준 그대로 기록했습니다.

YouTube 프로필에는 동영상 60개로 표시되어 있고 텍스트에는 두 목록의 45개와 15개가 있습니다. 수는 맞지만 두 목록이 서로 다른 분류인지 전체 목록인지 원문만으로 확정할 수 없어 각 항목에 목록 유형을 따로 남겼습니다.

## 저장 경로

- `database/x/posts/YYYY/MM/`: 명시 날짜별 게시물
- `database/youtube/videos/undated/`: 절대 게시일과 개별 URL이 없는 항목
- `database/soop/catches/YYYY/MM/`: 명시 날짜별 캐치
- `database/soop/catches/relative-or-unknown-date/`: 상대 시각이 표시된 캐치
- `database/platforms/`: 계정 링크와 프로필 스냅샷

각 활동 파일은 배치와 원문 행 위치를 포함한 ID를 사용합니다. 같은 제목이 반복되어도 URL/ID로 같은 항목임이 확인되지 않는 한 별도 기록으로 둡니다. X/YouTube 해시태그를 원문 표기 그대로 추출했고, SOOP은 `[캐치]`를 뺀 `titleText`와 나머지 대괄호 라벨인 `seriesLabels`를 추가했습니다.

## 관찰한 패턴

- 초기 X 발췌의 날짜·해시태그 패턴은 검증되지 않은 수동 자료였으므로 현재 데이터 현황이나 인사이트로 사용하지 않습니다. 확인된 X 항목은 [공개 프로필 수집 기록](x-profile-2026-10-31.md)에서만 관리합니다.
- YouTube 제목 60개 중 24개에 `#이주인`, 17개에 `#vtuber`가 포함됩니다. 짧은 리액션/대화형 제목, 팬클립, ASMR, 크리에이터 태그가 검색·필터 후보로 보입니다.
- 길이가 있는 YouTube 15개 항목의 게시 시점은 `11개월 전`, `1년 전`, `2년 전` 같은 상대 표현입니다. 제목/수치만 있는 45개 항목에는 텍스트상 길이와 게시일이 없습니다.
- SOOP 캐치의 명시 날짜는 `2026-07-28`부터 `2026-10-24`까지입니다. 월별 행 수는 7월 8개, 8월 37개, 9월 4개, 10월 44개입니다. 나머지 27개는 상대 시각이므로 절대 날짜로 바꾸지 않았습니다.
- 같은 SOOP 제목이 여러 번 등장합니다. 예를 들어 `[어인섬] 엽떡` 제목은 8회, 할로윈 의상 제목은 7회 보입니다. J-pop, 운동, 게임 세션 제목도 반복됩니다. 원본 ID/URL이 없고 표시 숫자도 다른 경우가 있어 각 행을 따로 남겼습니다.
- 캐치 11개에는 `비공개`, 7개에는 `블라인드` 상태가 표시되어 그대로 기록했습니다.
- SOOP 캐치 뒤 작은 숫자는 원문에 지표명이 없어 `unknown`으로 저장했습니다.
- X의 초기 프로필 소개/팔로우 수는 수동 스크랩에서 온 검증 불가 스냅샷이어서 계정 데이터에서 제거했습니다. YouTube는 구독자 235명/동영상 60개, SOOP은 캐치 1,803개로 표시되었습니다. 해당 수치는 수집 당시 스냅샷입니다.
